# Mahabharat Studio

Planning and prototypes for a Hindi Mahabharat animated series, built on the Katha Studio pipeline.

- `research/FEASIBILITY.md`: can the series meet 10+ minute episodes in 20 minutes of generation? Start here.
- `research/research-story.md`: parvas, episode plan, characters, sets, hard shots, sensitivity, diction list.
- `research/research-render.md`: renderer cost breakdown and the layer-cache compositor plan.
- `research/research-tts.md`: VoxCPM2 speed-up paths, pronunciation control, API fallbacks.
- `prototypes/`: measurement scripts and their timing results.
